# Smart Number Operations Toolkit

A console-based Java application that provides basic arithmetic operations and common number operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- GCD
- LCM
- Power calculation
- Sum of digits
- Armstrong number checking
- Prime number checking

## Technologies Used

- Java
- Java Scanner
- Java Math

## Concepts Practiced

- Methods
- Loops
- Conditional statements
- Switch-case
- Recursion
- Mathematical operations
- User input using Scanner

## How to Run

1. Clone the repository.
2. Open the project in any Java IDE or VS Code.
3. Compile the Java file.
4. Run the program.
5. Select an operation from the menu.
